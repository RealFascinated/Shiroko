# Privacy Policy for Shiroko

**Last updated: 2026-09-08**

This Privacy Policy explains what data the Shiroko Discord bot collects and
how it is used. Shiroko is a hobby project run by an independent operator
and is not affiliated with Discord Inc.

## 1. Data collected

Shiroko processes only the data it needs to operate its features. This is
limited to the identifiers Discord provides (such as user, server, and
channel IDs) and records of how you use the bot's features, collected only
in servers Shiroko has been added to.

## 2. How data is used

Collected data is used solely to operate the bot's features and keep them
fair and functional. Data is never sold, used for advertising, or shared
with third parties, except where required by law.

Note that Discord itself processes your data when you use Discord, under
[Discord's Privacy Policy](https://discord.com/privacy). Shiroko cannot
control that.

## 3. Retention

Data is kept only for as long as needed to operate the Service. Removing
Shiroko from a server stops all future collection in that server but does
not automatically delete data already stored.

## 4. Your rights and data deletion

You may request a copy of the data Shiroko holds about you, or request that
it be deleted, by contacting the operator (see §6 below). Include your
Discord user ID so your records can be found. Deletion is performed manually
within a reasonable time.

Server administrators may request deletion of their server's stored data the
same way.

## 5. Children

Shiroko is only for people who are allowed to use Discord (13 years or older
in most regions, or older where local law requires). It does not knowingly
collect data from anyone below that age.

## 6. Changes and contact

This policy may change as the bot evolves; changes take effect when the
"Last updated" date above is revised. Questions or deletion requests:
shiroko@fascinated.cc.
